Epidemiologists use this page to explain an evidence snapshot, a source period, and a methodology version without mixing those clocks.

Atlas shows a short **evidence snapshot** on [Atlas Explorer](/explore) and [Compare](/compare) before technical release identifiers. Technical identifiers sit inside **Inspect provenance**.

## Release semantics

| Label | What it means |
| --- | --- |
| **Evidence snapshot** | Geography in scope, source periods, and the county-review methodology version. |
| **Selected release** | The county bundle on screen. An assembly date is not an observation date. |
| **Evidence scope** | Counties or geographies this release includes or excludes. |
| **Source periods** | Upstream observation, reporting, or publication periods. Not when Atlas built the release. |
| **Scoring methodology** | Versioned rules for the county review score. Separate from source periods and assembly time. |
| **Release generated** | When Atlas finished the bundle. Not a case date. |
| **Release loaded** | When the public API served this release. It may differ from generation time. |
| **Methodology version (technical ID)** | Scoring-rule id. Missing metadata shows **Unavailable**. The app does not infer a version. |
| **Release ID (technical ID)** | Bundle id for links, exports, and support. |

Open **Inspect provenance** on Atlas Explorer for exact IDs and timestamps.

## How county scoring works

The county review score is a **derived follow-up-priority measure**. It highlights where published Lyme surveillance, tick and pathogen evidence, and selected contextual inputs may warrant review together. It is not a diagnosis, individual exposure estimate, proof of underreporting, or forecast of future cases.

**Deterministic scoring methodology** applies fixed, inspectable rules. **Semantic scoring methodology** uses a newer ruleset named in metadata. Compare counties inside one release and one methodology version. Keep source periods, release generated or loaded, and methodology version separate. An absent or invalid value shows **Unavailable**. Atlas does not invent a retrieval date.

For value states and uncertainty language, continue with [Evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty).
