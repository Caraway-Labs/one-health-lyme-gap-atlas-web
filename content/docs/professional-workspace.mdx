Epidemiologists use this page to open the signed-in workspace, keep a shared review address, and read each evidence state as its own state.

The navigation has six destinations: **Atlas Explorer**, **Compare**, **Ask Atlas**, **Feed**, **Settings**, and **Docs**. It also opens **Data Provenance** and **Resources**. Atlas Explorer is the map, the county list, expandable county evidence, and suggested follow-up on one address. Compare and Ask Atlas stay dedicated pages. There is no separate Review, Explore, Investigate, or Action destination, and Ask Atlas does not open a side panel.

<Callout title="Interpret with care" type="warn">
  A review-priority signal focuses follow-up. It is not a diagnosis, a
  disease-burden estimate, or an individual risk.
</Callout>

Sign-in is required. A signed-out visit to a workspace address goes to sign-in and comes back to the address you asked for. An older bookmark is then opened as the matching Atlas Explorer state. Reading these docs does not require a sign-in.

Use [current capabilities](/docs/current-capabilities) for what is released, planned, experimental, or not supported.

## Open Docs from the workspace

**Docs** opens this site in a new browser tab. The workspace tab keeps its page and URL, including geography, release, and compare context. Docs opens at the documentation home. Search and the sidebar move you through this reference. A heading link stays on that heading after you reload the documentation tab. Return to the original workspace tab to resume the review.

## Workspace destinations

| Destination | Address | Status | What you can do |
| --- | --- | --- | --- |
| Atlas Explorer | [/explore](/explore) | Available now | See a national or one-state picture, then open county evidence or suggested follow-up on that address. |
| Compare | [/compare](/compare) | Available now | Compare two counties on aligned measures. The page does not rank a winner. |
| Ask Atlas | [/askatlas](/askatlas) | Experimental/demo | Ask reviewed-literature questions when that service is enabled. |
| Feed | [/app/feed](/app/feed) | Available now | Scan recent items from approved trusted sources. The sidebar label is Research & News. |
| Resources | [/resources](/resources) | Available now | Open CDC guidance, state programs, and regional centers. |
| Data Provenance | [/data-provenance](/data-provenance) | Available now | Read where the current release's evidence comes from. |
| Settings | [/app/settings](/app/settings) | Available now | Save a default jurisdiction and optional profile details. |
| Docs | [/docs](/docs) | Available now | Open this reference in a new tab. |

`/app/review`, `/app/compare`, and `/app/assistant` permanently open `/explore`, `/compare`, and `/askatlas`. Supported details on those addresses stay. Older addresses such as `/overview`, `/geographic_explorer`, `/investigate`, `/app/explore`, `/app/investigate`, and `/app/action` are not extra destinations. After sign-in they open Atlas Explorer. A valid county on an old investigation address opens county evidence. A valid county on an old action address opens suggested follow-up. An address with no county opens that scope's picture. On a state picture, Atlas Explorer then selects the first published review candidate and writes that county into the address. An address that names a county which does not validate opens with `selection=required` and does not substitute another county.

One saved evidence-brief address, `plan=evidence-brief` on `/app/action`, still opens that brief. It is not a navigation destination. **Return to county evidence** goes back to Atlas Explorer with the county, scope, release, and period that brief was using. Surveillance planning is not a released workflow.

The footer links to the [Privacy page](/privacy) and to [AI / Responsible Use](/ai-ethics).

## How context travels

| Detail | What it selects |
| --- | --- |
| **scope** | United States or one state. |
| **county** | One five-digit county FIPS code. |
| **compare** | Up to two county FIPS codes. |
| **dataset** | The governed release id, when the page has one. |
| **period** | A calendar date, when the page supports one. |
| **mode** | Atlas Explorer only. Omit it for the map and list. `evidence` opens county evidence. `follow-up` opens suggested follow-up. |

Atlas Explorer, Compare, and Ask Atlas keep the details that destination accepts. A compare pair stays with the county when you open county evidence. Feed, Resources, Data Provenance, and Settings do not carry this context. Docs leaves it on the original workspace tab. Sort and page position stay on Atlas Explorer browse.

## Atlas Explorer

Choose **United States** or one state. National scope is a bounded picture. It is not a ranking of every U.S. county. The map and the county list describe the same release. Use the list when the map is unavailable. **View county evidence** stays on this address. **Back to map** returns to the map and list. **Compare this county** opens Compare. **Ask Atlas** opens the dedicated page. **Suggested follow-up** reads that county's review result. It does not start an intervention.

A saved default jurisdiction applies only when the address has no `scope` or `county`. An address that already names a place stays there. Changing the default does not rewrite an open page and does not hide other places.

### Loading, empty, unavailable, and error

| State | What it means |
| --- | --- |
| **Loading** | Request in progress. Not an evidence label and not a score. |
| **Empty** | No row returned. Atlas does not invent a county or a next step. |
| **Available** | Governed inputs exist, including a published zero. |
| **Limited** | A signal exists, and a documented limitation constrains how to read it. |
| **Unavailable** | Absent, invalid, or out of scope. Atlas shows Unavailable, not zero. |
| **Unknown** | Stays unknown. Not inferred from a source date. |
| **Error** | Request failed. Retry does not create Unavailable evidence. A failed refresh does not keep the previous facts as current. |

## Compare

Choose **First county** and **Second county**. Each row keeps that county's unit, period, and availability. A withheld comparison explains why the values were not treated as a simple difference. The page does not produce a winner, a combined score, or a rank. **View first county evidence** and **View second county evidence** open Atlas Explorer. **Ask Atlas about this comparison** opens Ask Atlas. Opening Ask Atlas from Compare does not ask the service to compare counties.

A loading list, a failed county list, and failed evidence are request states. Feed can be empty, disabled, or failed. It does not send alerts or keep a saved-article library. Data Provenance opens without a sign-in. Provenance beside a result stays on that result.

## Settings

Settings at [/app/settings](/app/settings) stores a profile for future Atlas Explorer sessions.

- **Default jurisdiction** is **United States** or one state from the current Atlas state list.
- **Role**, **organization**, and **job title** are optional and can stay empty. Roles include preferring not to say, general public citizen, and district, state, state-director, and national epidemiologist roles.
- **Save profile** confirms the default only after the account profile accepts it. If not, the form keeps what you typed and says the save was not confirmed. The default applies the next time Atlas Explorer opens without a scope in the URL.
- **Sign out**, **Export**, and **Remove all data** are the account actions. Privacy stays on the [Privacy page](/privacy).

Settings does not generate or revoke an API key, and it does not manage saved comparisons, saved investigations, or alerts. See [API, MCP, and access](/docs/api-mcp-and-access).

## Ask Atlas

**Ask Atlas** opens the [Ask Atlas page](/askatlas). It does not open a side panel or a dialog. Atlas Explorer and Compare open this page. They do not display the previous county or comparison. The county, comparison, or release on the previous page is not sent with the question. Old `page_ref` links open this page without that reference.

Enabled literature chat shows cited evidence or an explicit unavailable-evidence outcome. When chat is off, Ask Atlas is unavailable and the other pages stay usable. That is a service state, not missing county evidence. Ask Atlas does not change filters or maps, run a workflow, or offer Structured or Both mode. Opening Ask Atlas from Compare does not ask the service to compare counties. History stays in this browser for up to 30 days. [/assistant](/assistant) is a separate public route. See [AI-enabled decision intelligence](/docs/ai-enabled-decision-intelligence).

## County PDF

A county PDF is offered when the measures share one county, release, and period, and Atlas can verify the file against the county, observations, sources, period, and caveats on screen. If that check cannot be completed, the PDF is unavailable. That is not a statement that the report contains none of a period, and it is not a claim that the county has no evidence. A failed download stays an error. The file is not reused from an earlier attempt. Read [evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty) before you treat a label as a conclusion.
