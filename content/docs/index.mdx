The One Health Lyme Gap Atlas is a public-health surveillance planning tool. It brings together published Lyme disease records and other public evidence so teams can decide where a closer review may be useful.

## What Atlas is — and is not

Atlas helps users explore patterns in public evidence at the county level. A review-priority score is a structured way to focus questions; it is not a diagnosis, an individual risk prediction, a measure of disease burden, or proof of causation.

The current release is an early public prototype. Some workflows are available now, while future capabilities such as broader intelligence feeds, saved workspaces, and richer integrations will be labeled as they are released.

## A quick start

1. Open the [Atlas Explorer](/) and choose a state or county.
2. Review the county list, map, and evidence panels together. The table and text summaries provide the same key findings without requiring a map.
3. Open **How to interpret the Atlas** to inspect sources, release dates, methodology, and limitations.
4. Share the URL when you want another person to review the same supported geography and filter state.

## Read the evidence carefully

Atlas combines measures that can have different geographies, years, publishers, and update schedules. The application displays the release and methodology information available for the current result. Check the source and vintage before comparing measures.

### Missing is not zero

An absent published county record can reflect zero reported cases, suppression, an unavailable source, a different reporting boundary, or another limitation. Do not treat a missing value as proof that no disease or surveillance activity exists.

### Start with provenance

For a defensible follow-up question, record the source, source vintage, geography, retrieval or load context when available, methodology version, and known limitations. Use the in-application data dictionary and methodology sections for context that must stay close to the result.

## Help and trustworthy use

Use the **Docs** link in the Atlas utility bar to open this help center in a new tab while keeping your analytical state in the original tab. The public [Privacy page](/privacy) and [AI Ethics page](/ai-ethics) remain the approved in-application sources for those topics; this guide does not create separate policy commitments.

## Developer and agent access

The public REST API is documented by its owning service. Start with the machine-readable [OpenAPI schema](https://api.carawaylabs.com/openapi.json) rather than copying endpoint definitions into this page. API examples must preserve provenance, missingness, versioning, pagination, and error semantics.

MCP/agent integration guidance will be published here when the owning service has a released, supported MCP contract. Until then, the Atlas web prototype does not promise a public MCP connection or tool surface.
