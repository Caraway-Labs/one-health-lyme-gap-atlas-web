## CanonicalGeographyAvailability [#schema-canonicalgeographyavailability]

The county exists, but its canonical geography data is not published yet.

### Operations

- [`GET /v1/geographies/{geography_type}/{geography_id}/availability`](/docs/api-reference/geographies/checkGeographyAvailability) — Check county geography availability

Type: `object`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `availability` | `UNAVAILABLE` | required | Always `UNAVAILABLE`: the county's geography data is not published. |
| `reason` | `CANONICAL_GEOGRAPHY_UNPUBLISHED` | required | Why the data is unavailable. The geography data has not been published. |
| `data` | `null` | required | Always `null`. The API returns no geography data or geometry. |
| `release_id` | `string` | required | Identifies the county directory release used to confirm the county. |
| `limitations` | array of `string` | required | Publication and representation boundaries, not scientific absence. |

## CollectionMeta [#schema-collectionmeta]

Paging, release, and availability details for a list response.

### Operations

- [`GET /v1/indicators`](/docs/api-reference/discovery/listIndicators) — List indicators
- [`GET /v1/measures`](/docs/api-reference/discovery/listMeasures) — List measures
- [`GET /v1/observations`](/docs/api-reference/observations/listObservations) — Query county observations
- [`GET /v1/sources`](/docs/api-reference/provenance/listSources) — List sources

Type: `object`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `next_page_token` | `string \| null` | optional | Send this value as `page_token` to get the next page, with the same filters. Do not parse it. `null` means there are no more pages. A token can stop working after a service restart. |
| `response_at` | `string (date-time)` | optional | When Atlas built this response, in UTC. It is not when the publisher last updated the data and not when the observation was made. |
| `availability` | `AVAILABLE \| UNAVAILABLE \| null` | optional | Whether Atlas has published results for the selection. It does not describe biological presence. Returned for observations and omitted on other collections. A later page that runs out of items stays `AVAILABLE`. |
| `reason` | `NO_PUBLISHED_RESULTS \| null` | optional | Why `availability` is `UNAVAILABLE`. `NO_PUBLISHED_RESULTS` means the first query found no published results. Omitted otherwise. |
| `release_id` | `string \| null` | optional | Identifies the published data release this query read. Results from different releases are not directly comparable. |
| `limitations` | array of `string` \| `null` | optional | Notes on what the availability result does and does not show. Returned with `availability` on observation collections and omitted elsewhere. |

| Value | Meaning |
| --- | --- |
| `AVAILABLE` | No description yet |
| `UNAVAILABLE` | No description yet |

### `reason` values

| Value | Meaning |
| --- | --- |
| `NO_PUBLISHED_RESULTS` | the first query found no published results. Omitted otherwise |

## CountyContextObservation [#schema-countycontextobservation]

A county population or rurality value, reported for a reference period or a vintage.

### Operations

- [`GET /v1/observations`](/docs/api-reference/observations/listObservations) — Query county observations

Type: `object`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `metadata_revision_id` | `string \| null` | optional | Identifies the reviewed metadata revision that describes this observation. `null` when none applies. |
| `observation_id` | `string` | required | Stable identifier of the observation. It also serves as the provenance reference. |
| `measure_id` | `string` | required | Identifier of the measure. See `/v1/measures/{measure_id}`. |
| `geography` | [GeographyIdentity](#schema-geographyidentity) | required | The place the value describes. |
| `temporal_grain` | `PERIOD \| VINTAGE_YEAR` | required | `PERIOD` for a dated reference period. `VINTAGE_YEAR` for a classification that has no dates. |
| `value` | `integer \| string \| null` | required | An integer for a population or category, or exact decimal text. `ZERO` is the integer 0. Read it with `value_state`. |
| `value_state` | [ValueState](#schema-valuestate) | required | How to read `value`. The `ValueState` schema explains each state and what a client should do. Never treat a `null` value as zero. |
| `unit` | `string` | required | Unit of `value`, such as `count` or `mm`. |
| `denominator` | `string \| null` | required | What the value is measured against, such as a population. `null` means Atlas supplies no denominator; do not infer one. |
| `strata` | object of `string` | optional | Breakdown the value applies to, such as an age group. Empty when the release has no strata. |
| `source_id` | `string` | required | Public key of the source resource. Use it with `/v1/sources/{source_id}`. It differs from `lineage_source_id` and `dataset_id`. |
| `lineage_source_id` | `string \| null` | optional | Identifies the source in Atlas lineage records. It differs from `source_id`. |
| `dataset_id` | `string \| null` | optional | Identifies the publisher's dataset. It differs from `source_id`. |
| `methodology_id` | `string \| null` | required | Identifies the methodology resource. Use it with `/v1/methodologies/{methodology_id}`. `null` when no methodology resource applies. |
| `methodology` | `string \| null` | optional | Short name of the method that produced the value. |
| `release_methodology_version` | `string \| null` | optional | Version of the methodology as published in this release. `null` when none. |
| `methodology_version` | `string` | required | Version of the transformation applied to this observation. It is separate from the version of the methodology resource. |
| `semantic_version` | `string` | required | Version of the data contract the value follows. It is separate from the API version and the application version. |
| `release_id` | `string` | required | Identifies the published data release the result came from. Results from different releases are not directly comparable. |
| `provenance_ref` | `string` | required | Identifies the provenance record for this observation. It is not a literature citation. |
| `source_label` | `string \| null` | optional | Display name of the source. `null` when none is published. |
| `source_vintage` | `string \| null` | optional | Reference year or period of the source dataset, such as `ACS 2018-2022`. It is not an annual value. |
| `source_url` | `string \| null` | optional | Web address of the source. `null` when none is published. |
| `source_published_at` | `string (date-time) \| null` | optional | When the publisher published the data. Includes a UTC offset. `null` when not recorded; do not assume the data is fresh. |
| `atlas_acquired_at` | `string (date-time) \| null` | optional | When Atlas retrieved the data from the publisher. Includes a UTC offset. `null` when not recorded. |
| `atlas_processed_at` | `string (date-time) \| null` | optional | When Atlas processed the data. Includes a UTC offset. It is not the response time. `null` when not recorded. |
| `limitations` | array of `string` | required | Factual notes on what the result does not show or where its evidence is bounded. Keep them with the value when you display or store it. |
| `evidence` | [EvidenceReference](#schema-evidencereference) | required | Compact pointer to the Atlas resource that backs this observation. |
| `environmental_context` | [EnvironmentalContext](#schema-environmentalcontext) \| `null` | optional | Coverage details. Present only for environmental measures. Exact decimal quantities may be strings. |
| `surveillance_context` | [SurveillanceContext](#schema-surveillancecontext) \| `null` | optional | Optional surveillance evidence. Omitted or `null` supports no claim about evidence state, comparability, or lag. |
| `period_start` | `string (date) \| null` | required | First date of the reference period. `null` for a classification vintage. |
| `period_end` | `string (date) \| null` | required | Last date of the reference period. `null` for a classification vintage. |
| `county_context` | [CountyContext](#schema-countycontext) | required | Describes the field the value came from. |

| Value | Meaning |
| --- | --- |
| `PERIOD` | for a dated reference period |
| `VINTAGE_YEAR` | for a classification that has no dates |


## EnvironmentalContext [#schema-environmentalcontext]

How completely the source covers a county and day. It is separate from `value_state`.

Area values are square meters. Exact decimal quantities may be strings.

### Operations

- [`GET /v1/observations`](/docs/api-reference/observations/listObservations) — Query county observations

Type: `object`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `coverage_status` | `COMPLETE \| PARTIAL_COVERAGE \| SOURCE_MISSING \| OUT_OF_SOURCE_COVERAGE` | required | How much of the county the source covers for this day. |
| `source_time_present` | `boolean` | required | Whether the source supplied a time for this observation. |
| `day_convention` | `string` | required | How the publisher defines a day. It is a labeled 24-hour period, not necessarily a midnight-to-midnight calendar day. |
| `expected_area_m2` | `number \| string \| null` | required | County area expected to be covered, in square meters. `null` when unknown. |
| `intersected_area_m2` | `number \| string \| null` | required | County area that overlaps the source grid, in square meters. `null` when unknown. |
| `source_supported_area_m2` | `number \| string \| null` | required | County area the source supports, in square meters. `null` when unknown. |
| `valid_area_m2` | `number \| string \| null` | required | County area with a valid source value for this day, in square meters. `null` when unknown. |
| `source_coverage_fraction` | `number \| string \| null` | required | Monthly share of the county area that the source supports. It is separate from daily completeness. |
| `valid_fraction_of_supported_area` | `number \| string \| null` | required | Daily share of the supported area that has a valid value. Atlas treats 0.95 as the completeness threshold. |
| `upstream_date_modified` | `string \| null` | required | Modification date the source reports. It is not the original publication date or the date the data first became available. |
| `weight_version` | `string` | required | Version of the area weights used to combine grid cells into a county value. |
| `geometry_version` | `string` | required | Version of the county boundaries used for the calculation. The API returns no boundary geometry. |
| `metadata_revision_id` | `string` | required | Identifies the reviewed metadata revision that describes this context. |

### `coverage_status` values

| Value | Meaning |
| --- | --- |
| `COMPLETE` | No description yet |
| `PARTIAL_COVERAGE` | No description yet |
| `SOURCE_MISSING` | No description yet |
| `OUT_OF_SOURCE_COVERAGE` | No description yet |

| Field | Type | Required | Description |
| --- | --- | --- | --- |

| `indicator_id` | `string` | required | Identifier of the indicator this measure belongs to. |
| `label` | `string` | required | Short display name of the measure. |
| `definition` | `string \| null` | required | Plain-language definition of the measure. `null` when none is published. |

- `OBSERVED`: a nonzero value the publisher reported. Use `value` as given.
- `ZERO`: a reported numeric zero. It is different from a missing value.
- `MISSING`: no value was reported and `value` is `null`. It is not zero.
- `SUPPRESSED`: the value exists but is withheld, and `value` is `null`. It is not zero. Do not estimate it.
- `UNAVAILABLE`: Atlas has no published result for this selection, and `value` is `null`. It does not mean zero or absence.
- `NO_COUNTY_LINKED_RECORD`: a governed status meaning no record is linked to the county. `value` is the text `no_county_linked_record`. It is neither null nor zero.
- `NO_RECORDS`: the publisher's literal "No records" result. `value` is the text `No records`. It does not establish biological absence.

Show these states differently from each other. Never turn `null` into zero.

## Tier1CountyPriority [#schema-tier1countypriority]

Model-assisted surveillance review priority for one county.

The priority helps decide where to look first. It is not a measure of disease or clinical
risk, and it is not a diagnosis.

Type: `object`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `county_fips` | `string` | required | Five-digit county FIPS code, with leading zeros. |
| `priority_tier` | `HIGH \| MEDIUM \| LOW \| null` | required | HIGH, MEDIUM, or LOW model-assisted surveillance review priority under the named tier policy; not disease risk. Null for NOT_ESTIMABLE. |
| `priority_percentile` | `number \| null` | required | Within-batch relative position among scored counties for this model and inference batch (0-100).
