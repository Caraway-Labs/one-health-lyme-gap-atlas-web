Call the public HTTP contract with an anonymous GET. The [API reference](/docs/api-reference) is generated from the pinned OpenAPI contract and links the raw spec. Machine-readable definitions stay on the API service.

Atlas results are not a diagnosis. Atlas results are not an estimate of an individual's risk. See [Evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty).

## Call public reads without an API key

Current-release metadata and county observations need no API key and no signed-in session. Collections return `data`, `meta`, and `links`. A single resource returns `data`. Errors use `application/problem+json` with `code`, HTTP `status`, `detail`, and `request_id`.

Reads return the current release only: no historical release, no arbitrary aggregation, and no geometry. Account, feedback, literature chat, and `/app` are outside this contract. Literature chat needs no account. `/assistant` and the legacy drawer stay public when enabled. `/app` requires sign-in. A saved jurisdiction is not a credential. See [the professional workspace](/docs/professional-workspace).

Task requests are in the [developer guides](/docs/develop). Start with the [quickstart](/docs/develop/quickstart).

## Copy a public read

County FIPS codes are five characters. Keep leading zeros. `case_count_floor_2023` is a privacy-protected case floor in `cases`, not a complete incidence count.

```sh
curl -fsS 'https://api.onehealthatlas.org/v1/indicators?page_size=10'
curl -fsS 'https://api.onehealthatlas.org/v1/measures?indicator_id=human_disease_burden&page_size=10'
curl -fsS 'https://api.onehealthatlas.org/v1/measures/case_count_floor_2023'
curl -fsS 'https://api.onehealthatlas.org/v1/observations?measure_id=case_count_floor_2023&geography_type=county&geography_id=08001&year=2023'
```

Repeat `geography_id` to compare counties. Use `year` or both `start_date` and `end_date`. Published county observations for this release use the annual 2023 period.

```sh
curl -fsS 'https://api.onehealthatlas.org/v1/observations?measure_id=case_count_floor_2023&geography_type=county&geography_id=08001&geography_id=08003&year=2023&page_size=1'
```

Send `meta.next_page_token` back as `page_token` with the other parameters unchanged. Stop when the token is null. The token is opaque and bound to that query and release. A rejected token means you start again. A page token is not a citation.

Follow `source_id` and `methodology_id` for publisher, vintage, and method limitations:

```sh
curl -fsS 'https://api.onehealthatlas.org/v1/sources/human'
curl -fsS 'https://api.onehealthatlas.org/v1/methodologies/human_confirmed_probable_case_floor_v1'
```

Read `value` with `value_state` and `unit`: `OBSERVED`, `ZERO`, `MISSING`, `SUPPRESSED`, `UNAVAILABLE`, `NO_COUNTY_LINKED_RECORD`, `NO_RECORDS`. Gaps and `SUPPRESSED` are not zero. The workspace shows **Suppressed**. `NO_COUNTY_LINKED_RECORD` is neither null nor zero. `NO_RECORDS` keeps `No records` and does not establish biological absence. A published `ZERO` stays a real zero.

## Handle limits and errors

Send one measure, `geography_type=county`, five-digit FIPS codes, and `year` or both dates. Rejected filters, strata, sorting, and aggregation use `RESOURCE_NOT_FOUND`, `INVALID_REQUEST`, `UNSUPPORTED_FILTER`, or `UNSUPPORTED_STRATIFICATION`. Keep `request_id`.

`429` and `503` may include `Retry-After` seconds. No numeric quota is published. Wait, then retry. Send `If-None-Match` for `304`. Details: [REST API](/docs/develop/rest).

## Reproduce a result

Save the URL, measure, FIPS codes, period, `release_id`, `semantic_version`, methodology id and version, source id, lineage source id, dataset id, source vintage, and limitations. The URL can change after a later release. The saved body, or a checksum, is the record. Name Atlas, V1, those ids, the retrieval date, and the publisher you received.

## Read canonical evidence

Indicators, measures, observations, sources, and methodologies are the current-release contract. Prefer them to a schema that changes with each upstream source. HTTP fields: [OpenAPI schema](https://api.onehealthatlas.org/openapi.json).

Tool definitions stay in the [Atlas MCP repository](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp). Released tools return the same evidence, source identity, and value state. Design and unreleased clinical connections: [Sources and canonical evidence](/docs/sources-and-canonical-evidence). Fields: [Provenance and evidence](/docs/develop/provenance).

## Use the MCP tools

Server: [Atlas MCP repository](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp). [ADR 0003](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/blob/d26ef2b72a2f9203a26ff45a3ad13f0f2ac104c9/docs/adr/0003-public-evidence-tools.md) accepts three anonymous read-only evidence tools. The [production receipt](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/pull/21#issuecomment-6116902766) records SHA `d26ef2b72a2f9203a26ff45a3ad13f0f2ac104c9` and exactly six tools; that receipt is historical. Production `tools/list` returned exactly four tools. Setup: [MCP clients](/docs/develop/mcp-clients).

| Tool | What you can request |
| --- | --- |
| `atlas_discover_indicators` | Published indicators and measures. Not county availability |
| `atlas_get_county_profile` | One five-digit FIPS and one to three measure-period selections. Empty is not a missing row, zero, biological absence, or proof of identity |
| `atlas_get_evidence_provenance` | Current source or methodology. Not an arbitrary observation id or a historical release |
| `atlas_resolve_geographies` | Identity from the CDC/ATSDR SVI 2022 county source. Not observations, adequacy, comparability, or a legal-boundary file |
| `server_status`, `atlas_smoke_test` | Absent from production `tools/list`. Unknown-tool error. `GET /healthz` is process health, not evidence |

Arguments stay in the [public evidence tool contract](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/blob/d26ef2b72a2f9203a26ff45a3ad13f0f2ac104c9/docs/public-evidence-tools.md). Tools keep value states, units, denominators, source identity, and limitations. They do not score, diagnose, compare scientifically, write, or accept private data or a caller-supplied URL. They are not a live EHR, TEFCA, patient-level, PHI, or clinical-laboratory connection.

The [2026-09-26 record](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/blob/e897207640919a9d6464233ade885ed5d9df8227/docs/operations/digitalocean-mcp.md) accepted those smoke tools in [`server.py`](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/blob/e897207640919a9d6464233ade885ed5d9df8227/src/atlas_lyme_mcp/server.py). That smoke-only receipt is historical. REST and OpenAPI stay authoritative. MCP does not replace them.

## Skip API keys on public reads

Do not send an API key, bearer token, or Settings secret. Settings does not generate, show, copy, revoke, or regenerate one. Future key controls are outside this release. An account session is not a public API key and does not replace anonymous `/v1` reads.
