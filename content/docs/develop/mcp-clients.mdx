Connect to one anonymous Streamable HTTP endpoint. Arguments stay in the [public evidence tool contract](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/blob/main/docs/public-evidence-tools.md). Reading rules: [evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty).

## Transport and auth

| Item | Supported | Sample |
| --- | --- | --- |
| Endpoint | `https://mcp.onehealthatlas.org/mcp` | HTTP 200 |
| Transport | Streamable HTTP, stateless JSON | JSON body. No `Mcp-Session-Id`. Send `notifications/initialized` |
| Accept | `application/json` and `text/event-stream` | Both |
| Protocol | `2025-06-18` | `protocolVersion` `2025-06-18`, `serverInfo` `atlas-lyme-mcp` `0.1.0` |
| Auth | None | Works without a credential. Do not send an API key, OAuth client, or Settings secret |
| Health | `GET https://mcp.onehealthatlas.org/healthz` | HTTP 200 `{"status":"ok"}`. Not an MCP tool |

`GET /mcp` stays `text/event-stream`. Calls are POST. `GET /sse` and `POST /messages` returned HTTP 404. Production does not publish a stdio endpoint.

`tools/list` returned exactly four tools: `atlas_discover_indicators`, `atlas_get_county_profile`, `atlas_get_evidence_provenance`, `atlas_resolve_geographies`. `resources/list` and `prompts/list` were empty. `server_status` and `atlas_smoke_test` returned `Unknown tool: server_status` and `Unknown tool: atlas_smoke_test`. See [API, MCP, and access](/docs/api-mcp-and-access).

## Claude Desktop

Use a custom connector. `claude_desktop_config.json` is for local stdio. Do not add this URL there, and do not select SSE.

Free, Pro, and Max: **Customize**, **Connectors**, **Add custom connector**. Team and Enterprise owners add it under **Organization settings**, **Connectors**. Free accounts allow one custom connector.

| Field                 | Value                                |
| --------------------- | ------------------------------------ |
| Name                  | One Health Lyme Gap Atlas            |
| Remote MCP server URL | `https://mcp.onehealthatlas.org/mcp` |
| Authentication        | No sign in                           |
| Request headers       | None                                 |

Claude reaches the connector from Anthropic's cloud. Keep the server public. Managed `transport` `http` is Streamable HTTP. Omit `oauth`, `headers`, and `headersHelper`.

```json
{
  "name": "one-health-lyme-gap-atlas",
  "transport": "http",
  "url": "https://mcp.onehealthatlas.org/mcp"
}
```

## Cursor

Add the server to `~/.cursor/mcp.json`, or a project `.cursor/mcp.json`. Keep existing servers. `type` `http` is Streamable HTTP. Do not set `sse` or `streamable-http`. Do not add `headers` or an `auth` object.

```json
{
  "mcpServers": {
    "one-health-lyme-gap-atlas": {
      "type": "http",
      "url": "https://mcp.onehealthatlas.org/mcp"
    }
  }
}
```

Reload MCP and confirm the four names. `atlas_resolve_geographies` with `{"geographies":[{"county_fips":"01001"}]}` checks identity only. A resolved county is not an observation.

## Custom client

Send one JSON-RPC message per POST. Do not send a credential. The sample initialize response omitted `Mcp-Session-Id`. If that header appears, send it later.

After `initialize`, send `notifications/initialized` before anything else. It has no `id`. A sample returned HTTP 202 and an empty body. Send `MCP-Protocol-Version: 2025-06-18` on that notification and every later request.

```sh
curl -fsS \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -X POST 'https://mcp.onehealthatlas.org/mcp' \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"example","version":"0.0.0"}}}'
```

```sh
curl -fsS \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  -X POST 'https://mcp.onehealthatlas.org/mcp' \
  --data '{"jsonrpc":"2.0","method":"notifications/initialized"}'
```

```sh
curl -fsS \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  -X POST 'https://mcp.onehealthatlas.org/mcp' \
  --data '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}'
```

The repository check client is `python -m atlas_lyme_mcp.check_client` with `MCP_URL=https://mcp.onehealthatlas.org/mcp`. It is not required for a REST read.
