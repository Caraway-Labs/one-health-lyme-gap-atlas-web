---
title: Indicators, measures, and observations
description: Discover indicators and measures, then read county observations with value states.
---

Discover ids, then query one measure for a county and period. An indicator groups measures. A measure is one variable. An observation is that variable for one place and period. Use an example id only when discovery returns it.

Atlas results are not a diagnosis. Atlas results are not an estimate of an individual's risk. See [Evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty).

## Discover ids

```sh
curl -fsS 'https://api.onehealthatlas.org/v1/indicators?page_size=100'
curl -fsS 'https://api.onehealthatlas.org/v1/measures?indicator_id=human_disease_burden&page_size=100'
curl -fsS 'https://api.onehealthatlas.org/v1/measures/case_count_floor_2023'
```

Indicator filters are optional `indicator_id`, `page_size`, and `page_token`. Measure filters are optional `measure_id`, `indicator_id`, `geography_type`, `page_size`, and `page_token`. Unknown path ids return HTTP 404 `RESOURCE_NOT_FOUND`.

A sample collection at `page_size=20` returned seven indicators and `next_page_token` null. The human-disease id was `human_disease_burden`, with measures `case_count_floor_2023`, `human_status`, `incidence_floor_2023`, and `state_unallocated_records_2023`. A later release can add or remove ids. Page until `next_page_token` is null.

Required fields: `measure_id`, `indicator_id`, `label`, `definition`, `semantic_version`. Also read `unit`, `denominator`, `geography_semantics`, `temporal_semantics`, `missingness_semantics`, `allowed_value_states`, `allowed_strata`, `methodology_id`, `source_ids`, and `limitations` when present. A null `denominator` was not supplied. Do not invent one.

## Query observations

`GET /v1/observations` requires:

| Parameter | Rule |
| --- | --- |
| `measure_id` | Exact id from discovery |
| `geography_type` | `county` for this query |
| `geography_id` | 1 to 500 five-digit county FIPS strings |
| `year` | 1900 through 2100, or omit it and send both dates |
| `start_date` and `end_date` | Inclusive. Send both, and omit `year` |
| `stratification` | Optional. The current release has no strata |
| `page_size` | Optional. 1 to 500. Default 100 |
| `page_token` | Opaque token from the previous page |

`case_count_floor_2023` uses 2023. Current land-cover measures use `2025`. Read `temporal_semantics`. Other enabled series can use other periods. See [Observation queries](/docs/develop/observation-queries).

```sh
curl -fsS 'https://api.onehealthatlas.org/v1/observations?measure_id=case_count_floor_2023&geography_type=county&geography_id=36061&year=2023'
```

The same county and measure, with `start_date` 2023-01-01 and `end_date` 2023-12-31 and no `year`, returns the same kind of HTTP 200 row. You cannot sort or aggregate. `sort=value`, `aggregation=sum`, and an unknown parameter each return HTTP 400 `UNSUPPORTED_FILTER`.

## Read value_state

`value` is a number, a string, or null. Null never means zero.

| State | Contract meaning |
| --- | --- |
| `OBSERVED` | Nonzero value the publisher reported |
| `ZERO` | Reported numeric zero. Different from a missing value |
| `MISSING` | No value was reported. It is not zero. `value` is null |
| `SUPPRESSED` | Withheld. It is not zero. `value` is null |
| `UNAVAILABLE` | No published result. Not zero or absence. `value` is null |
| `NO_COUNTY_LINKED_RECORD` | Literal `no_county_linked_record`. Neither null nor zero. Not evidence of absence |
| `NO_RECORDS` | Publisher literal `No records`. It does not establish biological absence |

A sample case-floor `strata` value was an empty object, not a breakdown.

Also keep period, unit, denominator, source, methodology, `semantic_version`, `release_id`, `provenance_ref`, `limitations`, and `evidence`. Optional `environmental_context` is reviewed environmental context only. Optional `surveillance_context` is published surveillance context on a supported slice. Omitted or null carries no evidence-state, comparability, or lag claim. Present objects have `evidence`, `methodology_comparison`, and `temporal_alignment`. `normalized_state` is a Data-owned state (`established`, `detected`, `unknown`, or null). The original publisher value stays in `value`. Missing context does not establish absence or temporal comparability. Types are in the [schema reference](/docs/api-reference/schemas).

## Match a response to an action

Shared status codes, including `QUERY_TOO_BROAD` above 10,000 results, live in [REST API](/docs/develop/rest). The API never truncates results. Observation-specific results:

- HTTP 200 `data: []` when no row matches, including sample FIPS `99999`. An unmatched county can be an empty page instead of HTTP 404 `RESOURCE_NOT_FOUND`.
- HTTP 400 `INVALID_REQUEST` for a missing period, `year` plus dates, `page_size` below 1, or `geography_type` other than `county` or `state`.
- HTTP 400 `UNSUPPORTED_FILTER` or `UNSUPPORTED_STRATIFICATION` for a rejected filter or stratum.
- `MISSING`, `SUPPRESSED`, `UNAVAILABLE`, `NO_COUNTY_LINKED_RECORD`, `NO_RECORDS`, null `environmental_context`, and null or omitted `surveillance_context` stay as returned.
- Detail HTTP 304 with an empty body when `If-None-Match` matches the `ETag`.
