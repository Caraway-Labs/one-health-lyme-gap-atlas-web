## 2026-10-25

Documentation and metadata release. Every change is `additive`. No route, status code, response shape, authentication rule, or data value changed. Generated clients keep working unchanged.

- **Added** — **Landing page**: `info.description` now explains what Atlas is, how to start, how to page, how errors work, and how to read results. It restates the interpretation limits once: results are not a diagnosis and not an estimate of an individual's risk. Read [API reference](/docs/api-reference).

- **Added** — **Tags and tag groups**: Operations are grouped under task-focused tags with descriptions, and shown in groups in the served reference. Summaries are shorter and start with a verb. Read [API reference](/docs/api-reference).

- **Added** — **Parameters**: Every parameter has a description that states the accepted form, bounds, and defaults. Read [API reference](/docs/api-reference).

- **Added** — **Schemas**: Every response schema and field has a description, including how to read `null` and each `value_state`. Read [Schemas](/docs/api-reference/schemas).
