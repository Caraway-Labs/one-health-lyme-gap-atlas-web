## Read machine-readable docs

[llms.txt](/llms.txt) indexes current pages. [llms-full.txt](/llms-full.txt) joins them. [Support page as Markdown](/docs/develop/support.md) and [Support page as MDX](/docs/develop/support.mdx) export the support URL. Add md or mdx to a page URL. The index is [docs.md](/docs.md) and [docs.mdx](/docs.mdx). Home: [https://onehealthatlas.org/docs](https://onehealthatlas.org/docs).

These exports are separate from the OpenAPI contract. `/v1` and OpenAPI `info.version` are different identifiers.

Contract questions go to the API repository. Guide wording goes to the web repository. [API, MCP, and access](/docs/api-mcp-and-access) records the MCP boundary. [MCP clients](/docs/develop/mcp-clients) has the Streamable HTTP recipes. The September 2026 smoke-only receipt is historical.

## Report a failed read

- Full request URL, with no Authorization header. Public reads do not use one.
- HTTP status and `content-type`.
- `request_id` from the problem body.
- `Retry-After` when the status is `429` or `503`.
- For an observation, `measure_id`, `geography_id`, period, `value_state`, `release_id`, and `semantic_version`.

There is no API key to rotate and no SDK version to report.

## Check what the contract omits

| Item | Status |
| --- | --- |
| Numeric quota and concurrency cap | Not in the public OpenAPI document. Honor `Retry-After` |
| Geography identity payload | HTTP `200` `GeographyUnavailable` (`CANONICAL_GEOGRAPHY_UNPUBLISHED`, `data` null) and no geometry. Polygons are `GET /v1/atlas/geometry` |
| Daily environmental measure | In the current catalog. Checked id: `nclimgrid_tavg_county_day`. See [Observation queries](/docs/develop/observation-queries) |
| API keys, required SDKs, required MCP | Outside anonymous public reads |
| Account, feedback, conversational AI, literature retrieval | Excluded from the public OpenAPI document |
