## Support

Include these items when you report a failed or surprising read:

- The full request URL, without an Authorization header. Public reads do not use one.
- The HTTP status and `content-type`.
- `request_id` from the problem body.
- `Retry-After` when the status is `429` or `503`.
- For a successful observation, `measure_id`, `geography_id`, period, `value_state`, `release_id`, and `semantic_version`.

There is no API key to rotate and no SDK version to report.

## Unavailable in this contract

| Item | Status |
| --- | --- |
| Numeric rate-limit quota and concurrency cap | Not published in the public OpenAPI document. Honor `Retry-After` |
| Geography identity payload | Declared route returns HTTP `200` `GeographyUnavailable` (`CANONICAL_GEOGRAPHY_UNPUBLISHED`, `data` null) and no geometry. Polygons are `GET /v1/atlas/geometry` |
| Daily environmental measure id | Present on 18 October 2026. The checked id is `nclimgrid_tavg_county_day`. Read `environmental_context` when that observation includes it. See [Observation queries](/docs/develop/observation-queries) |
| API keys, required SDKs, and required MCP tools | Not part of anonymous public reads |
| Account, feedback, conversational AI, and literature retrieval | Excluded from the public OpenAPI document |
