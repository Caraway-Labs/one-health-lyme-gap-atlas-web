Contract questions belong with the API repository. Guide wording belongs with the web repository. [API, MCP, and access](/docs/api-mcp-and-access) records the current MCP boundary: development smoke tools do not read Atlas data, and production MCP is not the data interface.

## Support

Include these items when you report a failed or surprising read:

- The full request URL, without an Authorization header. Public reads do not use one.
- The HTTP status and `content-type`.
- `request_id` from the problem body.
- `Retry-After` when the status is `429` or `503`.
- For a successful observation, `measure_id`, `geography_id`, period, `value_state`, `release_id`, and `semantic_version`.

There is no API key to rotate and no SDK version to report.

## Unavailable in this contract

| Item | Status |
| --- | --- |
| Numeric rate-limit quota and concurrency cap | Not published in the public OpenAPI document. Honor `Retry-After` |
| Geography identity payload | Declared route currently returns `503` `CANONICAL_DATA_UNAVAILABLE` and no geometry |
| Daily environmental measure id | Described on the observations operation. Not present in the current measures catalog. Read `environmental_context` only when an observation includes it |
| API keys, required SDKs, and required MCP tools | Not part of anonymous public reads |
| Account, feedback, and conversational routes | Not part of these read examples |
