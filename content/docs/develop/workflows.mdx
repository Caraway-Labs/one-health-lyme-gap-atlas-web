Each workflow is an anonymous GET for a county in the lower 48 states or the District of Columbia. Replace ids when discovery returns different ones.

Atlas results are not a diagnosis. Atlas results are not an estimate of an individual's risk. See [Evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty).

## Query a county

Retrieve one county's current-release case-count floor.

<HttpClientTabs
  path="/v1/observations"
  query="measure_id=case_count_floor_2023&geography_type=county&geography_id=36061&year=2023"
/>

Open `source_id` and `methodology_id` from that body:

<HttpClientTabs
  requests={[
    { path: "/v1/sources/human" },
    { path: "/v1/methodologies/human_confirmed_probable_case_floor_v1" },
  ]}
/>

`GET /v1/counties/{fips}` is the legacy county document, including release metadata. A sample `GET /v1/counties/00000` returned HTTP 404, detail `County or dataset release not found`, and no `code`. Use observations for `value_state`. FIPS `36061`, `year=2023`, was `OBSERVED`. FIPS `99999` was HTTP 200 and `data: []`. FIPS `08001` was `MISSING` with `value` null.

## Compare geographies

Repeat `geography_id` for one measure and period, up to 500 counties. There is no rank field. Do not send `sort` or `aggregation`.

<HttpClientTabs
  path="/v1/observations"
  query="measure_id=case_count_floor_2023&geography_type=county&geography_id=08001&geography_id=36061&year=2023"
/>

Order is measure id, county FIPS, period start, then observation id. A sample HTTP 200 page had FIPS `08001` `MISSING` with `value` null, then FIPS `36061` `OBSERVED` with a numeric `value`. Both shared `measure_id`, `unit` `cases`, year 2023, and `release_id`. Compare `value_state` before `value`. A county missing from `data` is not a zero. Follow `next_page_token` with the same filters. The checked 404 is an unknown measure path.

## Retrieve environmental context

`environmental_context` is optional, only for reviewed environmental context, and descriptive weather only: no causal, disease-risk, or ML claim. `surveillance_context` appears only with published surveillance context on a supported slice. Omitted or null context carries no evidence-state, comparability, or lag claim, and it does not establish absence.

Read `coverage_status` first: `COMPLETE`, `PARTIAL_COVERAGE`, `SOURCE_MISSING`, or `OUT_OF_SOURCE_COVERAGE`, independent of `value_state`. `day_convention` is the labeled 24-hour period. `source_coverage_fraction` is monthly source-supported area over legal area. `valid_fraction_of_supported_area` is daily valid area over source-supported area, threshold 0.95. Areas may be numbers or strings. `geometry_version` names analysis geometry and has no polygons.

The catalog includes the January 2025 daily measures. Rejected parameters are in [Observation queries](/docs/develop/observation-queries). Do not invent an id.

Land cover (`land_cover_context`) is published for `09110` and `51013` only. A true zero stays zero. An unselected county has no observation. Limitations are land-cover context only, with no Lyme causal or risk estimate.

<HttpClientTabs
  path="/v1/observations"
  query="measure_id=nlcd_forest_area_share_county_year&geography_type=county&geography_id=09110&year=2025"
/>

That request returned HTTP 200, `value_state` `OBSERVED`, `unit` `fraction`, temporal grain `YEAR`, and `environmental_context` null. The land-cover row is not a weather object.

<HttpClientTabs
  path="/v1/observations"
  query="measure_id=nlcd_forest_area_share_county_year&geography_type=county&geography_id=08001&year=2025"
/>

FIPS `08001` is outside the selected geographies. The request returned HTTP 200 and `data: []`. The empty page is not a zero share.

## Read common response states

HTTP 200 can be a row, `data: []`, or a partial set. An absent county is not a zero. Read `value_state` first. HTTP 404 `RESOURCE_NOT_FOUND` is declared, and a legacy 404 can omit `code`. HTTP 400 is `INVALID_REQUEST`, `UNSUPPORTED_FILTER`, `UNSUPPORTED_STRATIFICATION`, or `QUERY_TOO_BROAD` above 10,000 results. The API never truncates results. HTTP 429 and 503 include `Retry-After`. Keep `request_id`. Limited rows stay `MISSING`, `SUPPRESSED`, `UNAVAILABLE`, or `NO_COUNTY_LINKED_RECORD`, with a null area or null context left null. `PARTIAL_COVERAGE`, `SOURCE_MISSING`, and `OUT_OF_SOURCE_COVERAGE` are coverage gaps.

## Reproduce and cite an observation

Save one response so you can explain it after the release moves. See [Provenance and evidence](/docs/develop/provenance#cite-from-discovery).

1. Save the request URL and the body, or a checksum.
2. Save `value_state`, `release_id`, `semantic_version`, methodology ids and versions, source id, lineage source id, dataset id, source vintage, and `limitations`.
3. Save the source, and the methodology when `methodology_id` is not null.
4. Save `meta.response_at` apart from `period_start`, `source_vintage`, and `source_published_at`. The response time shows when Atlas built the response. It does not show when the publisher last updated the data.

Name Atlas, `/v1`, measure, FIPS, period, `release_id`, `semantic_version`, retrieval time, publisher, and dataset. `provenance_ref` is not a literature citation. A `page_token` is not a citation. The URL is the current release, so the saved body is the record. A 400 body is not an observation. Cite a gap by `value_state` and the null or literal value.

## Download a county report

Use `GET /v1/counties/{fips}/report.pdf` for one county in the lower 48 states or the District of Columbia. `template` defaults to `county-v1`. A sample for FIPS `11001` returned HTTP 200. A scoring PDF is a review-priority report. An evidence PDF repeats observations, lineage, value states, and limitations. Parameters are in the [county report reference](/docs/api-reference/counties#county_report_pdf_v1_counties__fips__report_pdf_get).

<Tabs items={["county-v1 scoring", "county-v2 evidence"]}>
  <Tab value="county-v1 scoring">

`county-v1` scores the report. `dataset_version` is optional. These settings are optional:

| Parameter                | Default | Bounds               |
| ------------------------ | ------- | -------------------- |
| `ecological_share`       | 65      | 40–85, multiple of 5 |
| `smooth_k`               | 50      | 5–200                |
| `missing_human_weakness` | 75      | 40–90, multiple of 5 |

`period_start`, `period_end`, and `measure_id` are forbidden on `county-v1`. One of them returns HTTP `422` `application/problem+json`. Sample for FIPS `36061`:

```json
{
  "type": "https://onehealthatlas.org/problems/http-422",
  "title": "Request failed",
  "status": 422,
  "detail": "Observation context requires county-v2.",
  "instance": "/v1/counties/36061/report.pdf",
  "request_id": "example-request-id",
  "errors": null
}
```

A pattern-matching unknown template returns HTTP `422` and detail `The requested county report template is not available.` Any other template returns HTTP `422` and detail `One or more request values are invalid.`

Success is `application/pdf` and `Cache-Control: public, max-age=300, must-revalidate`. `If-None-Match` can return `304`.

<HttpClientTabs
  body="bytes"
  path="/v1/counties/36061/report.pdf"
  query="template=county-v1"
/>

  </Tab>
  <Tab value="county-v2 evidence">

`county-v2` requires `dataset_version` (the observation `release_id`), exact `period_start` and `period_end`, and 1–20 distinct `measure_id` values, repeated or comma-separated. A missing release, period, or measure list, a duplicate id, more than 20 ids, or a reversed period returns HTTP `422`. Sample:

```json
{
  "type": "https://onehealthatlas.org/problems/http-422",
  "title": "Request failed",
  "status": 422,
  "detail": "county-v2 requires release, exact period and distinct measures.",
  "instance": "/v1/counties/36061/report.pdf",
  "request_id": "example-request-id",
  "errors": null
}
```

An unresolved `dataset_version` returns HTTP `404`, detail `County or dataset release not found`. An unknown measure returns HTTP `404` `RESOURCE_NOT_FOUND`, detail `Measure has no published county observations.` Missing or mismatched provenance returns HTTP `503`. A report over the resource limit returns HTTP `413`.

County-v1 score settings still apply. A sample that also sent `ecological_share=65` returned HTTP `200` and `Cache-Control: no-store`. Success uses `Cache-Control: no-store`. The service revalidates context before a cached response or `304`. `ETag` remains. Replace the release id below with the `release_id` you cite.

<HttpClientTabs
  body="bytes"
  path="/v1/counties/36061/report.pdf"
  query="template=county-v2&dataset_version=governed-2026-10-15-january-climate-prod&period_start=2023-01-01&period_end=2023-12-31&measure_id=case_count_floor_2023"
/>

  </Tab>
