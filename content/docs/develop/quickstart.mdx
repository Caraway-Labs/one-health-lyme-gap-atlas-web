Send one anonymous request for the 2023 published case-count floor for New York County. The measure id `case_count_floor_2023` is the example on the public observations operation. County FIPS `36061` is in the lower 48.

Use an HTTPS client. Skip the account and the API key. These client tabs stay in sync with the workflow guides and the REST pagination example: curl, Python httpx, R httr2, or TypeScript fetch. The choice remains after a reload.

<Steps>
<Step>

### Make a request

<HttpClientTabs
  path="/v1/observations"
  query="measure_id=case_count_floor_2023&geography_type=county&geography_id=36061&year=2023"
/>

`curl -f` hides error bodies. Drop `-f` when you need to read a problem response.

#### Try this request

This playground sends that anonymous GET through the docs site. It adds no API key and leaves the response unchanged.

</Step>

### Read the response

A successful body is a collection. Check `value_state` before you read `value`. Read `value` with `unit`.

<Callout title="Interpret with care" type="warning">
  `case_count_floor_2023` is a privacy-protected surveillance floor, in `cases`.
  A case floor is not a diagnosis, a complete count, or an individual risk.
</Callout>

| Field | Meaning |
| --- | --- |
| `data` | Observation records for this query. An empty array means this page has no rows. |
| `value_state` | How to read `value` on each row. Check it before you read `value`. |
| `meta.next_page_token` | Opaque continuation. `null` means this query is exhausted. Send it unchanged with the same filters. |
| `meta.response_at` | When Atlas built the response, in UTC. It does not date the publisher update or the observation. |
| `meta.availability` | Whether this selection has published results. Read it before you use `data`. |
| `links.self` | Link to this page. The contract allows `null`. |

Keep `limitations` with the value you store. This sample is trimmed from a response for release `governed-2026-10-15-january-climate-prod`. Read `value` and `release_id` from your own response. A later release can change them.

### Follow provenance

Copy `source_id` and `methodology_id` from the observation you received. The example uses `human` and `human_confirmed_probable_case_floor_v1`.

<HttpClientTabs
  requests={[
    { path: "/v1/sources/human" },
    { path: "/v1/methodologies/human_confirmed_probable_case_floor_v1" },
  ]}
/>

Detail routes return `data`. An unknown id returns HTTP 404 `RESOURCE_NOT_FOUND`. A matching `If-None-Match` on a source or methodology returns HTTP 304 and an empty body. This observation collection ignores `If-None-Match` and returns HTTP 200.

</Step>
<Step>

### Handle problems

Use this table for the quickstart URL, and for the same query with another county FIPS, period, or extra parameter. Handle an empty page, a bad request, and a retry before you look up the other codes.

| State | What you receive | What to do |
| --- | --- | --- |
| Observed value | HTTP 200, a row, `value_state` `OBSERVED`, numeric `value` | Record `value`, `unit`, the period, `release_id`, and `semantic_version` |
| Zero or gap | HTTP 200 and `value_state` `ZERO`, or `value` null with `MISSING`, `SUPPRESSED`, or `UNAVAILABLE` | Keep `ZERO` as numeric zero. Leave a gap null. Do not substitute zero |
| Empty page | HTTP 200, `data` `[]`. First query: `meta.availability` `UNAVAILABLE` and `reason` `NO_PUBLISHED_RESULTS`. A later empty page stays `AVAILABLE` | An empty page does not establish source coverage or biological absence, and it is not HTTP 404 |
| Bad request | HTTP 400. Read `code`, `detail`, and `errors` | Change the request and send it again. For this annual measure, send `year` or both `start_date` and `end_date`, and do not send both. `INVALID_REQUEST` covers a missing or inconsistent parameter. Send `geography_type=county`. `state` returns `UNSUPPORTED_FILTER` |
| Retry | HTTP 429 `RATE_LIMITED`, or HTTP 503 `SERVICE_UNAVAILABLE`, with header `Retry-After` | Wait the seconds in `Retry-After` when the header is present, then send the same request again. Without the header, follow [Retries](/docs/develop/errors#retries). The public document does not publish a numeric quota |

The other codes and states are in [Errors and retries](/docs/develop/errors): [Value states](/docs/develop/errors#value-states), [INVALID_REQUEST](/docs/develop/errors#invalid_request), [UNSUPPORTED_FILTER](/docs/develop/errors#unsupported_filter), [UNSUPPORTED_STRATIFICATION](/docs/develop/errors#unsupported_stratification), [QUERY_TOO_BROAD](/docs/develop/errors#query_too_broad), [RESOURCE_NOT_FOUND](/docs/develop/errors#resource_not_found), [RATE_LIMITED](/docs/develop/errors#rate_limited), [HTTP 413](/docs/develop/errors#http-413), [HTTP 414](/docs/develop/errors#http-414), [HTTP 503](/docs/develop/errors#http-503), and [Retries](/docs/develop/errors#retries).
