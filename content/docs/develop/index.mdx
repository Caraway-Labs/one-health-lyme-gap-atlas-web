These guides take a developer from no Atlas context to one successful public REST read, and they explain the semantics that an operation name leaves out. Parameter tables, component schemas, and generated examples stay in the API reference. This section explains how to use the contract.

## Access

Ordinary public reads are anonymous HTTPS GET requests. They require no API key, no signed-in session, no SDK, and no MCP server. These guides call the public API at `https://api.onehealthatlas.org`. The HTTP contract is `/v1`. The OpenAPI `info.version` is a separate application version.

Send the request URL with its query string. A collection returns `data`, `meta`, and `links`. A single resource returns `data`. Errors use `application/problem+json`.

## Where the reference lives

The authoritative document is the public [OpenAPI schema](https://api.onehealthatlas.org/openapi.json). The [Swagger reference](https://api.onehealthatlas.org/docs) and [ReDoc reference](https://api.onehealthatlas.org/redoc) render that same document.

The generated reference for that contract uses `/docs/api-reference`, with `discovery`, `observations`, `provenance`, `geographies`, `atlas`, `counties`, `states`, and `schemas`. Those pages are produced from the pinned public spec. These guides name that location and do not copy its operation catalog.

## Two public route families

These guides cover two route families. Read the family you called.

| Family | Routes | Error shape |
| --- | --- | --- |
| Canonical current-release resources | Indicators, measures, observations, sources, methodologies, and geography identity | Problem details with a stable `code` |
| Legacy Atlas analytics and exports | County and state review, scores, display geometry, rankings, and PDF reports | Existing status codes, including `422`. A problem body may omit `code` |

Account, feedback, and conversational routes are not part of these read examples.

## Geography used in examples

Atlas product geography for these guides is the lower 48 states and the District of Columbia. Examples use county FIPS `36061` (New York County, New York), `08001` (Adams County, Colorado), `09110` (Capitol Planning Region, Connecticut), and `51013` (Arlington County, Virginia). Preserve leading zeros. Five-digit FIPS strings are identifiers, so keep them as strings.

## Limits recorded with the contract

The public document does not publish a numeric request quota. Honor `Retry-After` on `429` and `503`. See [REST API](/docs/develop/rest).

`GET /v1/geographies/{geography_type}/{geography_id}` is declared, and its description says delivery currently returns `503` with `CANONICAL_DATA_UNAVAILABLE` and no geometry. See [Geography](/docs/develop/geography).

The observations operation describes separately enabled January 2025 environmental measures that carry `environmental_context`. The current `GET /v1/measures` catalog does not list a measure id for that daily series. See [Workflow guides](/docs/develop/workflows).
