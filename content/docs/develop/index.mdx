Make an anonymous HTTPS GET to `https://api.onehealthatlas.org`. Public reads need no API key, signed-in session, SDK, or MCP server. The HTTP contract is `/v1`. OpenAPI `info.version` is a separate application version.

Send the URL and query string. A collection returns `data`, `meta`, and `links`. A single resource returns `data`. Errors use `application/problem+json`.

Atlas results are not a diagnosis. Atlas results are not an estimate of an individual's risk. Read limits with the value in [Evidence, provenance, and uncertainty](/docs/evidence-and-uncertainty).

## Read the route family you called

| Family | Routes | Error shape |
| --- | --- | --- |
| Canonical resources | Indicators, measures, observations, sources, methodologies, geography identity | Problem details with a stable `code` |
| Legacy analytics and exports | County and state review, scores, geometry, rankings, PDF reports | Statuses such as `422`. A problem body may omit `code` |

Conversational AI, literature retrieval, account, and feedback routes are outside this contract.

## Use example geographies

Product geography is the lower 48 states and the District of Columbia. Examples use county FIPS `36061` (New York County, New York), `08001` (Adams County, Colorado), `09110` (Capitol Planning Region, Connecticut), and `51013` (Arlington County, Virginia). Preserve leading zeros. Keep five-digit FIPS values as strings.

## Apply the result limit

A query may select up to 10,000 results. A broader query is rejected. The API never truncates results. The public document does not publish a numeric request quota. Honor `Retry-After` on `429` and `503`. See [REST API](/docs/develop/rest).

`GET /v1/geographies/{geography_type}/{geography_id}` returns HTTP 200, `availability` `UNAVAILABLE`, `reason` `CANONICAL_GEOGRAPHY_UNPUBLISHED`, `data` null, and no geometry. Polygons are `GET /v1/atlas/geometry`. See [Geography](/docs/develop/geography).

January 2025 environmental measures carry `environmental_context`. The catalog includes those daily ids. Slice queries and rejected parameters are in [Observation queries](/docs/develop/observation-queries). Optional `surveillance_context` appears only with published surveillance context on a supported slice. See [Workflow guides](/docs/develop/workflows).
