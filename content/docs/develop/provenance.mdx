Cite a row with its value, `value_state`, and provenance together. Leave a null timestamp null.

`meta.response_at` is the response time. The response time shows when Atlas built the response. It does not show when the publisher last updated the data.

<Callout title="Interpret with care" type="warn">
  Atlas results are not a diagnosis. Atlas results are not an estimate of an
  individual's risk. Published human values are privacy-protected floors, not
  complete incidence counts. See [Evidence, provenance, and
  uncertainty](/docs/evidence-and-uncertainty).
</Callout>

## Keep fields with the value

| Field | Role |
| --- | --- |
| `observation_id` | Id and provenance reference |
| `measure_id` | Exact measure |
| `geography` | Type and `geography_id` |
| `period_start`, `period_end`, `temporal_grain` | Inclusive period and grain |
| `value`, `value_state`, `unit`, `denominator` | One set. Null is not zero |
| `source_id` | Public source key |
| `lineage_source_id`, `dataset_id` | Not `source_id` |
| `methodology_id` | Null when ungoverned |
| `methodology_version` | Transformation version |
| `release_methodology_version` | On some rows |
| `semantic_version` | Contract version |
| `release_id` | Not comparable across releases |
| `provenance_ref` | Not a literature citation |
| `source_vintage`, `source_label`, `source_url` | Publisher context |
| `source_published_at`, `atlas_acquired_at`, `atlas_processed_at` | Observation clocks. Null is unknown |
| `limitations` | Keep with the value |
| `evidence` | Type, id, optional source, version, release, uri |
| `surveillance_context` | Optional. Null has no comparability or lag claim |

In the synthetic example, `evidence.resource_type` is `observation` and `resource_id` repeats the observation id. On the sample case-floor row, `provenance_ref` equals `observation_id`. That match is not a second citation format.

## Read a null value

`MISSING`, `SUPPRESSED`, and `UNAVAILABLE` require null `value`. Keep `limitations`. `NO_COUNTY_LINKED_RECORD` is not evidence of absence. `NO_RECORDS` does not establish biological absence. States: [Errors and retries](/docs/develop/errors#value-states).

## Resolve source and methodology

Replace ids from [Cite from discovery](#cite-from-discovery) with ids on your row. A source adds `publisher`, `release_version`, `source_version`, `published_at`, `upstream_updated_at`, and `source_retrieved_at`. On sample `human`, `publisher` was set and those four timestamps were null. Observation `atlas_acquired_at` is separate and was present.

<section aria-labelledby="deprecated-source-timestamps">

## Deprecated source timestamps

The [Source](/docs/api-reference/schemas#schema-source) schema marks `published_at` and `atlas_acquired_at` deprecated. Those fields belong to the source. An [Observation](/docs/api-reference/schemas#schema-observation) keeps its own timestamps, and the contract does not mark that set deprecated.

| Object | Field | Mark | What it measures |
| --- | --- | --- | --- |
| Source | `published_at` | Deprecated | Former publisher time |
| Source | `atlas_acquired_at` | Deprecated | Former acquisition time |
| Source | `upstream_updated_at` | Current | Publisher update. Null if unknown |
| Source | `source_retrieved_at` | Current | Retrieval. Null if unknown |
| Observation | `source_published_at` | Current | Publisher time. Null is unknown |
| Observation | `atlas_acquired_at` | Current | Acquisition, when governed |
| Observation | `atlas_processed_at` | Current | Processing, when governed |

Only the Source `atlas_acquired_at` is deprecated.

A sample `GET /v1/sources` returned six sources, each with `published_at`, `atlas_acquired_at`, `upstream_updated_at`, and `source_retrieved_at` null. The `human` source still named its publisher. A sample county `36061` row had `source_published_at` null, `atlas_acquired_at` 2026-09-07T17:21:14.768948-07:00, and `atlas_processed_at` null. A null source field does not clear the observation timestamp.

Methodology `version` is the resource version. Observation `methodology_version` is the transformation version. Keep both, with `methodology_id`, `measure_id`, `description`, `limitations`, `semantic_version`, and `release_version`. Unknown ids return HTTP 404 `RESOURCE_NOT_FOUND`. Matching `If-None-Match` returns HTTP 304 and an empty body.

</section>

## Read the other clocks

| Clock | What it measures |
| --- | --- |
| `period_start` and `period_end` | Governed period |
| `source_vintage` | Vintage label. Not an annual value |
| `meta.response_at` | When the response was built |
| `environmental_context.upstream_date_modified` | Upstream modification metadata. Not original publication |

A generated timestamp does not become the surveillance date. `environmental_context` is descriptive weather coverage. A null object does not supply it. `normalized_state` is a Data-owned state (`established`, `detected`, `unknown`, or null). The original publisher value stays in `value`.

## Keep source identity after normalization

An adapter and a terminology mapping can still emit this observation shape. The mapping may annotate meaning. It does not replace `source_id`, `lineage_source_id`, `dataset_id`, or `source_vintage`. `MISSING`, `SUPPRESSED`, and `UNAVAILABLE` are not rewritten into `ZERO`.

Fields: [OpenAPI schema](https://api.onehealthatlas.org/openapi.json) and [provenance reference](/docs/api-reference/provenance). atlas_get_evidence_provenance reads a current source or methodology. atlas_get_county_profile reads explicit selections. Both keep value state, source identity, and limitations. atlas_resolve_geographies does not establish that an observation exists. Contract: [public-evidence-tools.md](https://github.com/Caraway-Labs/one-health-lyme-gap-atlas-mcp/blob/d26ef2b72a2f9203a26ff45a3ad13f0f2ac104c9/docs/public-evidence-tools.md). The September 2026 smoke-only receipt is historical. See [API, MCP, and access](/docs/api-mcp-and-access) and [Sources and canonical evidence](/docs/sources-and-canonical-evidence).

## Read source and methodology results

Status codes, including `QUERY_TOO_BROAD` above 10,000 results, are in [REST API](/docs/develop/rest). The API never truncates results. `GET /v1/sources` can return HTTP 200 and `data: []` on an exhausted page. Null timestamps and a null `methodology_id` stay null.
