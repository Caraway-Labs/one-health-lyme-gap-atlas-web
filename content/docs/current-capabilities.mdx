Epidemiologists use this page to choose a supported workflow and to keep a planned or experimental idea separate from a released capability.

<Callout title="Interpret with care" type="warn">
  A review-priority signal is not a diagnosis, a disease-burden estimate, or an
  individual risk estimate. Atlas does not predict an outbreak with certainty or
  act for a public-health authority.
</Callout>

## Capability status

Atlas uses four status labels:

- **Available now** — verified in the current public release and appropriate to document as user behavior.
- **Planned** — part of the product direction, but not available to rely on today.
- **Experimental/demo** — available only in a constrained, feature-gated, or validation context. Do not treat it as a production commitment.
- **Not supported** — outside the current product promise or deliberately excluded from the public experience.

## What you can do today

| Capability | Status | Boundary |
| --- | --- | --- |
| Front Porch at `/` | Available now | Public introduction. No county scores, results map, or comparison. |
| Atlas Explorer | Available now | National scope is a bounded picture, not a ranking of every U.S. county. |
| Compare two counties | Available now | No winner and no five-county comparison. |
| Inspect evidence and provenance | Available now | Check source, geography, vintage, release, method, freshness, and limitations. |
| Share a workspace address | Available now | Record the release and method with the URL. A later release may differ. |
| County PDF | Available now | A failed verification check makes the PDF unavailable. That is not a claim that the report contains none of a period. |

## Authenticated professional workspace

These routes require sign-in. The [professional workspace](/docs/professional-workspace) guide describes each destination. Older public bookmarks open Atlas Explorer after sign-in. They do not keep a separate public map.

| Capability | Status | How it supports investigation | Important boundary |
| --- | --- | --- | --- |
| Atlas Explorer at [/explore](/explore) | Available now | Map, list, county evidence, and suggested follow-up. | A default applies only with no scope and no county. A state picture with no county selects the first published review candidate. An invalid county opens with `selection=required` and is not replaced. |
| Model-assisted surveillance review priority | Available now | Read a published HIGH, MEDIUM, or LOW tier for the selected county when its release matches the selected evidence release. | Atlas withholds a tier from a different release, and withholds it when the governed release for the page is not known. A withheld, missing, or not-estimable result is not shown as LOW. This is review prioritization, not disease risk or predicted incidence. It is separate from the rules-based county review score. Forecasts are not released. |
| Compare at [/compare](/compare) | Available now | Compare two counties on aligned measures. | This page does not rank a winner. |
| Settings at [/app/settings](/app/settings) | Available now | Save United States or a state as the next Atlas Explorer start, plus optional role, organization, and job title. | Optional fields can stay empty. The default does not change evidence values or block other geographies. |
| Docs from the workspace | Available now | Open this reference in a new tab. | The original workspace tab keeps its URL. Docs is not in-page help. |
| Ask Atlas at [/askatlas](/askatlas) | Experimental/demo | Reviewed literature when enabled. | The previous county or comparison is not sent. Service off leaves the other pages usable. No side panel, Structured mode, or Both mode. History stays in this browser. |
| Feed at [/app/feed](/app/feed) | Available now | Scan recent items from approved trusted sources and open the publisher page. | An empty, disabled, or failed feed is its own state. Feed does not send alerts or keep a saved-article library. |
| Data Provenance at [/data-provenance](/data-provenance) | Available now | Read the current release source catalog and links to the methodology guides. | The page does not replace provenance beside a result, and it does not add sources the release did not return. |
| Evidence brief | Experimental/demo | A direct `plan=evidence-brief` address still opens that brief and returns to county evidence. | It is not a workspace destination. Surveillance planning is not released. |
| API keys in Settings | Not supported | Public API reads do not use a key. | Settings does not generate or revoke a key. See [API, MCP, and access](/docs/api-mcp-and-access) and the [developer quickstart](/docs/develop/quickstart). |

## Capabilities that are not current promises

| Capability | Status | What this means for you |
| --- | --- | --- |
| Historical release trends | Not supported | The public explorer exposes one active release. A generated date is release metadata, not the observation date. |
| Guaranteed outbreak prediction or automated public-health action | Not supported | Atlas surfaces signals and investigation candidates. It does not predict with certainty or act for an authority. |
| Clinical diagnosis or person-level exposure risk | Not supported | Atlas supports population-level review. It is not a clinical or individual-risk tool. |
| Additional clinical, laboratory, jurisdictional, or other governed sources | Planned | Future sources are designed to enter the same evidence model. The current release stays open-data-first. See [Sources and canonical evidence](/docs/sources-and-canonical-evidence). |
| Live EHR, TEFCA, patient-level, PHI, or production clinical-laboratory ingestion | Not supported | No live EHR or production clinical-laboratory feed is in this release. |
| AI-generated findings treated as authoritative | Experimental/demo | Keep AI grounded in approved evidence, show limitations, and retain human review. |
| Alerts, private feeds, or account-based evidence access | Not supported | An account does not unlock different evidence or change a score. Alerts are not released. Feed lists trusted-source items and does not keep a saved library. |
| Separate public map, five-county comparison, or Investigation Workspace | Not supported | Older `/overview`, `/geographic_explorer`, and `/investigate` bookmarks open Atlas Explorer after sign-in. |
